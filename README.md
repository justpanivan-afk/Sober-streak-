# SOBER//STREAK

Минималистичное приложение для отслеживания дней без алкоголя с граффити-акцентами.

## Что уже есть
- ежедневная отметка через головоломку;
- локальное сохранение серии дней;
- напоминание каждый день в 21:00;
- исторический факт после/рядом с испытанием;
- медали каждые 7 дней;
- экраны «День», «Медали», «Ещё»;
- тёмный минималистичный дизайн с оранжевым граффити-акцентом.

## Запуск
1. Установить Node.js.
2. `npm install`
3. `npx expo start`
4. Для iPhone открыть через Expo Go или собрать production build через EAS.

Для реального App Store-релиза нужно добавить Apple Developer account, иконки/скриншоты, privacy policy и собрать подписанный iOS build.
